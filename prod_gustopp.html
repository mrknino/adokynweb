GusTop

Sistema para el control de fidelidad de clientes. ¿Tienes un negocio en donde te gustaria recompensar la filedad de tus clientes cada vez que hagan una compra? GusTop es el sistema ideal para ti, puedes registrar a tus clientes que esten en el plan de fidelidad, llevar un registro de las compras que hagan y en cada compra otorgarles puntos que luego pueden usar para intercambiar por productos. El sistema tambien cuenta con metricos para medir tus ganancias, un registro con fecha y hora de cada transaccion, etc.

Con este programa puedes:

  1. Llevar un registro de clientes
  2. Llevar un sistema de tarjeta de puntos
  3. Llevar un registro de transacciones tanto de dinero como de puntos
  4. Generar reportes del listado de clientes, registro de movimientos y tarjetas en el sistema. Todos los reportes pueden exportarse en archivos de Excel
